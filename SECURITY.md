# Security Policy

## Supported Versions

Velin is currently under active development. Security fixes are generally
provided for the latest released version.

| Version | Supported |
| ------- | --------- |
| 0.5.x   | :white_check_mark: |
| < 0.5    | :x: |

Users are encouraged to keep Velin updated to the latest release.

## Reporting a Vulnerability

If you discover a security vulnerability in Velin, please report it
privately rather than opening a public GitHub issue.

You can report security vulnerabilities by contacting:

**Email:** msppunjab@gmail.com

Please include as much information as possible, including:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected Velin version
- The affected operating system, if applicable
- Any relevant screenshots, logs, or proof of concept

### What to Expect

We will acknowledge the report when possible and investigate the issue.

If the vulnerability is confirmed, we will work toward a fix and release it
as soon as reasonably possible. Depending on the severity and complexity of
the issue, the timeline for a fix may vary.

Please allow reasonable time for the issue to be investigated and addressed
before publicly disclosing the vulnerability.

Thank you for helping keep Velin and its users safe.
